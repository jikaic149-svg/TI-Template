# 简单文本行服务

调用方提供固定存储，`Service_Line_Feed` 每次接收一个字节。
允许可打印 ASCII，LF 或 CRLF 结束一行；空行、非法字符、行内 CR 和超长行被拒绝。
错误后丢弃到 LF，随后可以解析新行。容量包含末尾 NUL，不分配动态内存。

READY 时存储含 NUL 结尾的完整行，内容只保证在下一次 Feed 之前有效。
上层立即检查命令名、参数个数与范围，再构造自己的强类型消息，不能发布该存储的指针。
示例只接受 `LED 0\n` / `LED 1\n`（也可 CRLF）；其他内容返回错误。

该服务不做 CRC，也不识别“合法字符被改成另一个合法字符”的传输错误。
是否需要更强校验由链路和执行后果决定；短指示灯命令适合简单验证，
运动控制或配置写入应另外确定完整性、有效期和执行反馈要求。

一个实例只由一个 Task 持有；不在 ISR 中解析，不自动连接 UART，不自动创建 Task。
未结束的行保留到后续输入；连接生命周期变更时，可由单一 owner 重新 Init 清除残留。

资料来源：用户确认的按场景选择校验方式。代码为本次新增实现。
测试覆盖边界长度、分段输入、CRLF、非法字符、超长丢弃与恢复。
