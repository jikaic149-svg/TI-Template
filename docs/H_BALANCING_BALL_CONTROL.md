# H 题车载平衡滚球控制设计草案

本文记录 H 题当前讨论形成的控制方案，作为后续机械、硬件、控制算法和产品 Task
设计的共同入口。本文描述的是候选产品方案，不代表通用模板已经实现对应行为，也不
代表已经通过实物验证。

## 1. 题目约束摘要

- 跑道由两段 `1.5 m` 直线和两个半径 `0.5 m` 的半圆组成，总长约 `6.14 m`。
- 黑线线宽为 `1.8 +/- 0.2 cm`；小车循迹模块只能使用红外光电模块。
- 纯小车项目要求一圈不超过 `20 s`，停车偏差不超过 `2 cm`。
- 带球项目要求 AB 段不超过 `8 s`、整圈不超过 `30 s`，球位误差绝对值不超过
  `1 cm`。
- 摆杆长 `25 cm`，凹槽内放置直径约 `1 cm` 的钢球；球位检测必须使用摄像头。
- 小车行驶中不能人工干预，且车体投影不能完全脱离轨迹线。

## 2. 当前总体结论

底盘采用“已知路径导航为主、红外低带宽纠偏、红外独立识别 A 点”的方案，而不是
让高增益循迹 PID 直接快速改变左右轮命令。目标是在保留黑线绝对约束的同时，降低
车体蛇形运动和角速度突变，为上层滚球控制提供平滑、可预测的运动前馈。

底盘与滚球作为两个控制系统设计，通过底盘运动状态耦合：

```text
跑道路径、编码器、陀螺仪、红外
                 |
                 v
      底盘导航、角速度和轮速闭环
                 |
                 +----> 底盘运动 Latest Value ----> 滚球控制
                 |
                 v
             左右轮电机
```

## 3. 底盘机械与坐标约定

- 使用两轮差速驱动，驱动轮轴中点作为底盘位姿参考点。
- 车体前进方向为 `+X`，左向为 `+Y`，逆时针偏航为正。
- 左右轮物理前进速度均为正，单位统一使用 `mm/s`。
- 闭环跑圈发车时锁存驱动轮轴中点原点和ICM相对yaw；最终停车必须同时回到同一位置并
  恢复同一航向，不能用单独的轮速归零、过A线或一圈里程代替终点位姿验收。
- 有效轮距 `B` 使用左右轮接地点之间的实测距离，不使用外壳标称尺寸。
- 小车唯一测试位置优先设置在驱动轮轴中点，便于统一停车和里程定义。
- 主红外阵列安装在驱动轮轴前方约 `40..60 mm`，保持刚性、居中并可调高度。
- A 点横向启停线只有 `5 cm` 长，不能假设整排八路探头都会同时变黑；优先增加
  位于中心线两侧的专用红外检测点。

## 4. 底盘控制结构

### 4.1 差速运动学

底盘平均速度和角速度为：

```text
v     = (vR + vL) / 2
omega = (vR - vL) / B
```

由目标平均速度和目标角速度得到左右轮目标：

```text
vL_target = v_target - B * omega_target / 2
vR_target = v_target + B * omega_target / 2
```

平均速度负责前进，角速度负责转向。路径控制、红外纠偏和角速度控制只生成目标角速度
或半差速量，不直接输出 PWM。

### 4.2 轮速闭环

每个驱动轮独立使用“分段线性前馈 + 速度 PI”：

```text
motor_effort = feedforward(wheel_speed_target)
             + speed_PI(wheel_speed_target - wheel_speed_measured)
```

- 左右电机分别标定前馈，不共用未经实测的速度—PWM曲线。
- 首轮标定点建议覆盖 `100/200/300/400/500 mm/s`。
- 低速死区可以使用带符号截距的分段线性模型，不强制曲线穿过原点。
- 速度目标的加速度和变化率由上游速度规划器控制；轮速环不再施加很慢的独立平滑，
  避免左右轮瞬态不同步而改变曲率。
- 发生目标或电机输出饱和时执行抗积分饱和。

### 4.3 路径导航主控

跑道参考曲率为：

```text
kappa = 0       # AB、CD 直线
kappa = +/-2.0  # BC、DA，单位 1/m
```

几何角速度前馈为：

```text
omega_feedforward = v_target * kappa
```

例如 `v_target = 0.25 m/s`、`R = 0.5 m` 时，圆弧目标角速度约为
`0.5 rad/s`。路径前视负责在直线和圆弧交界附近逐渐建立曲率，避免目标角速度阶跃。

位姿估计使用编码器累计位移和陀螺仪偏航角速度融合。该估计没有绝对横向观测，轮胎
滑移、轮径误差、陀螺零偏和初始摆放误差会随行驶累计，因此不能把纯里程计视为绝对
定位。

### 4.4 角速度闭环

有陀螺仪时，对真实车体角速度闭环。角速度控制器输出附加半差速：

```text
delta_v = B * omega_target / 2
        + yaw_rate_PI(omega_target - omega_measured)
```

再由 `v_target +/- delta_v` 生成左右轮目标。若没有独立陀螺仪，不额外使用同一组
轮速编码器构造重复的角速度内环；此时路径/线偏差控制直接生成半差速目标。

### 4.5 红外弱纠偏

红外不直接高带宽打舵，只对导航角速度增加低频、限幅修正：

```text
omega_line = clamp(K_line * low_pass(line_error),
                   -omega_line_limit,
                   +omega_line_limit)

omega_target = omega_navigation + omega_line
```

初始设计范围：

- 红外误差低通时间常数约 `0.1..0.3 s`；
- 红外修正角速度限制约 `0.05..0.1 rad/s`；
- 不使用线误差积分；
- 对目标角速度或半差速增加斜率限制。

这样路径导航承担主要转弯，红外只缓慢消除横向累计误差。完全关闭红外纠偏可以作为
对照测试，但正式方案暂时保留弱纠偏，以提高换场地、不同电量和不同初始姿态下的重复
性，并降低题面合规解释风险。

### 4.6 饱和处理

左右轮目标必须同时满足：

```text
abs(v_target) + abs(delta_v) <= wheel_speed_limit
```

超限时优先降低公共平均速度，保留转弯需要的半差速，禁止分别粗暴裁剪单轮目标。否则
单轮饱和会同时改变平均速度和曲率，并引起路径误差、反向纠正和蛇形运动。

## 5. 速度规划与滚球前馈接口

速度规划器输出平滑的速度、加速度和角速度参考。带球项目初始建议以约
`250 mm/s` 巡航，并使用约 `150..250 mm/s^2` 的纵向加速度范围；最终值由实物测试
确定。

滚球系统主要需要纵向加速度而不是恒定车速。底盘向滚球控制发布一个单槽 Latest
Value，至少包含：

```text
timestamp
sequence
commanded_forward_speed_mps
commanded_forward_acceleration_mps2
measured_forward_speed_mps
estimated_forward_acceleration_mps2
measured_yaw_rate_radps
valid
```

其中命令速度必须从最终完成路径混合、斜率限制和饱和处理后的左右轮目标计算：

```text
v_commanded = (vL_target_final + vR_target_final) / 2
a_commanded = derivative(v_commanded)
```

滚球控制优先使用及时、平滑的 `a_commanded` 做前馈，再使用编码器或 IMU 得到的低通
实际加速度做慢速修正。禁止把原始编码器速度差分直接送入摆杆控制。

## 6. 建议执行周期

- 当前产品控制骨架周期为 `10 ms`，底盘导航、红外纠偏、角速度环和轮速环可先统一
  在 `100 Hz` 控制周期内计算。
- 各环虽然采样频率相同，但闭环带宽应满足：轮速环最快，角速度环其次，路径/红外
  横向修正最慢。
- 编码器、UART 和其他 ISR 只采样、搬运或通知，不在 ISR 中运行路径或 PID 算法。
- 控制算法使用真实 `dt`，不把名义 RTOS Tick 当成精确采样周期。

## 7. A 点检测与停车

启动时小车已经位于 A 点，因此 A 点检测必须在车辆明确离开起点后重新使能。建议利用
里程作为搜索门：接近一圈末段后降低速度，再使用专用红外传感器识别横向启停线。

停车偏差需要结合以下实物量标定：

- A 点传感器相对车辆唯一测试点的纵向偏移；
- 触发延迟；
- 制动前速度；
- 电机和轮胎的制动距离。

纯小车和闭环带球跑圈的最终静止位姿均以发车位姿为目标；需要统计“通过A”的成绩时刻可
在A点锁存，但不能再把A后320 mm作为最终停车点。终点横杠负责纵向锚定，灰度中心负责
横向锚定，ICM相对发车yaw负责航向锚定。当前位置至少满足题面`<=20 mm`，角度容差需
单独冻结。当前代码只做前瞻线性停车，尚未实现三误差同时收敛，也不得宣称已经达标。

## 8. 调试顺序

1. 核对左右电机和编码器物理前进方向。
2. 标定轮径、每圈计数、有效轮距和左右速度前馈。
3. 调通两个独立轮速 PI。
4. 不使用红外闭环，验证给定平均速度和角速度的差速运动。
5. 调通陀螺仪角速度闭环。
6. 建立跑道路径和前视导航，低速完成整圈。
7. 加入低带宽红外纠偏，比较横向误差和角速度平滑度。
8. 调通 A 点检测、减速和停车补偿。
9. 在不同电量、初始摆放和载荷下连续跑圈，记录重复性。
10. 最后向滚球控制开放带时间戳的底盘运动 Latest Value。

建议记录的关键诊断量包括：线偏差、导航/红外/最终目标角速度、实测角速度、左右轮
目标和实测速度、速度/半差速饱和状态、最终纵向加速度前馈及 A 点检测状态。

## 9. 当前待确认项

- 底盘电机型号、减速比、电机驱动和供电电压。
- 轮胎有效直径、编码器输出轴每圈计数和有效轮距。
- 红外模块具体型号、采样频率、输出极性和安装高度。
- IMU具体型号、安装方向、角速度噪声和零偏。
- 导航路径前视距离、红外弱纠偏增益和限幅。
- 带球/纯小车两种速度规划及停车模式的产品选择方式。
- 底盘运动 Latest Value 的最终 Topic 名称、所有权和超时语义。

## 10. 滚球系统讨论入口

后续滚球系统按以下链路继续收敛：

```text
摄像头球位 -> 位置/速度估计 -> 球位控制 -> 摆杆目标角
                                         ^
                          底盘纵向加速度前馈

摆杆目标角 -> 机械逆映射 -> 无刷伺服内环 -> 曲柄连杆 -> 实际摆杆角
```

需要依次确认球位视觉的帧率与延迟、球状态估计方法、目标轨迹、摆杆角限幅和斜率、
无刷电机控制模式以及是否使用独立摆杆角度传感器。

## 11. 滚球最终候选结构

最终性能方案可以使用“两个前馈 + 状态反馈 PID”：

```text
theta_command = model_scale * theta_model_feedforward
              + chassis_scale * theta_chassis_feedforward
              + theta_feedback
```

在小角度、纯滚动近似下：

```text
theta_model_feedforward   = -7 * reference_acceleration / (5 * g)
theta_chassis_feedforward = -chassis_acceleration / g
theta_feedback            = Kp * position_error
                          + Kd * velocity_error
                          + Ki * position_error_integral
```

`model_scale` 和 `chassis_scale` 是无量纲实物修正系数，理论初值均为 `1`。轨迹模型
前馈负责球的计划运动，底盘前馈抵消小车纵向加速度，PID 只修正模型、摩擦、视觉和
机械误差。

相机位置可以进入二状态 Kalman 估计器得到球位置和速度；若实测模型残差存在明显的
慢变化偏置，再考虑增加扰动加速度状态。使用扰动估计补偿时，不同时使用很强的积分，
避免两者重复消除同一偏差。

上述结构是最终候选上限，不是首个实现目标。±4 度范围内重力项近似线性，但 PVC
摩擦、滚滑切换、连杆回差、相机延迟和执行器限幅仍然存在。复杂估计器不能替代机械
和基础闭环验证。

## 12. 滚球最小调试模型

首轮调试只保留：

```text
固定摆角命令 -> 无刷电机内部角度伺服 -> 曲柄连杆 -> 摆杆 -> 钢球
```

使用最小模型：

```text
ball_acceleration = -K_theta * beam_angle
K_theta ~= 5 * g / 7
```

此阶段不使用：

- 相机在线反馈；
- Kalman、模型预测或扰动估计；
- 球位 PID；
- 底盘运动回传；
- 轨迹模型前馈；
- 底盘加速度前馈。

无相机闭环测试只能验证方向、机械、执行器和近似模型，不能完成题目要求，也不能证明
钢球已经稳定在指定位置。测试过程可以用普通录像离线读取刻度，不让录像数据参与
实时控制。

## 13. 分级调试路线

| 级别 | 输入与控制 | 目的 | 进入下一级的条件 |
|---|---|---|---|
| L0 | 无球，写死摆杆角度 | 验证无刷、曲柄、连杆和摆角映射 | 正负方向、零点、重复性正确，无卡滞 |
| L1 | 有球，无在线相机，写死摆角波形 | 验证球运动方向、线性量级和滚滑情况 | 多次运动方向一致，位移量级可重复 |
| L2 | 静止底盘，相机位置直接 PID | 完成中心定点闭环 | 可从小偏差回到中心且不持续振荡 |
| L3 | 静止底盘，相机 PID，简单参考斜坡 | 完成 `0 -> +5 cm -> -5 cm` | 5 秒内完成且误差满足目标 |
| L4 | 移动底盘，相机 PID，无任何前馈 | 判断纯 PID 是否已经足够 | 在目标车速和启动过程中记录最大误差 |
| L5 | 按证据逐项增加单个增强 | 只修复已经观测到的瓶颈 | 每次只加入一个前馈或估计器并复测 |

不预先实现所有 L5 功能。只有 L4 的日志证明纯 PID 在特定场景下不足时，才加入与该
问题对应的最小增强。

### 13.1 L0：无球机械摆角测试

先取下钢球，按以下角度逐项命令：

```text
0 deg -> +0.5 deg -> 0 deg -> -0.5 deg -> 0 deg
      -> +1.0 deg -> 0 deg -> -1.0 deg -> 0 deg
      -> +2.0 deg -> 0 deg -> -2.0 deg -> 0 deg
```

每个位置保持约 `0.5..1.0 s`，记录电机角、实际摆杆角和重复回零结果。确认：

- 命令正方向与定义一致；
- 曲柄不接近死点；
- 球头不顶死，连杆不弯曲；
- 正反向回到零点时没有明显不同的实际摆角；
- 摆杆中位和机械限位留有足够余量。

如果没有独立摆杆角传感器，至少使用量角工具或固定标尺测量，不能只根据电机命令角
判断连杆输出。

### 13.2 L1：无相机闭环的写死波形测试

钢球放在中心点，首个测试波形建议为：

```text
beam angle =  0 deg, hold 1.0 s
beam angle = -1 deg, hold 0.4 s
beam angle = +1 deg, hold 0.4 s
beam angle =  0 deg, hold 1.0 s
```

然后反向重复一次。按当前正方向定义，负角使球向摆杆自由端运动，正角负责减速。理想
纯滚动模型下，`1 deg` 倾角产生约 `0.122 m/s^2` 加速度；先加速 `0.4 s` 再反向减速
`0.4 s`，理论总位移约为：

```text
displacement ~= acceleration * time^2 ~= 0.0195 m
```

即约 `2 cm`。实际值与理论值不同是允许的，测试重点是多次重复是否一致。若运动过猛
或出现滑动，先降为 `0.5 deg`；首轮不超过 `+/-1 deg`。

使用录像离线读取第一段恒角加速位移，可以粗略辨识：

```text
K_theta ~= -2 * displacement / (beam_angle_rad * time^2)
```

应分别测试 `+0.5/-0.5/+1.0/-1.0 deg`，比较正反方向增益、死区和重复性。此步骤的
结果决定理论 `5*g/7` 是否能作为后续初值。

### 13.3 L2：静止底盘的直接 PID

加入车上相机，但不使用 Kalman、模型前馈或底盘数据。相机每个新帧直接给出球位置，
PID 输出摆杆目标角：

```text
error = measured_position - target_position
theta_command = Kp * error + Ki * integral(error) + Kd * derivative(error)
```

简化约束：

- 只在收到新相机帧时用该帧真实 `dt` 更新 PID；两帧之间保持上次摆角命令。
- 首次调试令 `Ki = 0`、`Kd = 0`，只增加 `Kp`。
- P 能把球拉回但出现振荡后，再增加 D；D 使用连续帧位置差分并限制噪声增益。
- PD 稳定后仍有可重复单向偏差，最后才加入很小的 I。
- 首轮目标只取中心点，手动将球偏离约 `1..2 cm` 后观察回中。
- 首轮总摆角限制在 `+/-2 deg`，确认稳定后再评估是否扩大到 `+/-4 deg`。

这个版本就是最小可用滚球闭环。若它已经满足静止和移动项目，不必为了理论完整而增加
Kalman 或前馈。

### 13.4 L3：PID 配合简单参考斜坡

保持静止底盘和同一套 PID，不使用模型加速度前馈。参考位置仅做线性斜率限制：

```text
0 cm -> +5 cm, reference rate about 5 cm/s
+5 cm -> -5 cm, reference rate about 5 cm/s
```

理论参考时间约为 `1 s + 2 s`，剩余约 `2 s` 用于稳定。此阶段不需要五次轨迹或模型
预测；只有简单斜坡导致明显超调时，才升级为连续加速度轨迹。

### 13.5 L4：移动底盘的纯 PID 基线

底盘先以约 `0.10..0.15 m/s` 平滑启动和匀速运行，滚球控制仍然只使用相机 PID，
完全不读取底盘速度、加速度或角速度。记录：

- 启动阶段最大球位误差；
- 匀速直线最大球位误差；
- 弯道最大球位误差；
- 相机帧间隔和控制摆角；
- 是否只在加减速时出现同方向偏差。

低速通过后再提高到约 `0.25 m/s`。这一基线决定复杂功能是否真的必要。

### 13.6 L5：按问题增加单项增强

只按以下证据路由升级：

- 仅在底盘启停时出现同方向偏差：先加入底盘加速度前馈。
- 静止底盘执行位置斜坡时明显落后：再加入轨迹模型前馈。
- 相机位置差分导致 D 项噪声大、速度估计不稳定：再加入二状态 Kalman。
- 长期存在稳定零偏：先标定摆杆水平零点，再在弱积分和扰动估计中二选一。
- 转弯时出现与球位置相关的重复偏差：最后评估是否加入 `omega^2*x` 项。

每加入一项，都重复 L2、L3、L4 的同一组测试并比较日志。禁止一次同时加入模型前馈、
底盘前馈和 Kalman，否则无法判断改善或恶化来自哪一项。

## 14. 简化方案的首个实现边界

若后续授权开始写代码，建议首个版本只实现：

- 无刷电机已有角度伺服命令；
- 摆杆角度零点和有限角度命令；
- L0/L1 的固定测试波形；
- 相机提供的最新球位置；
- 静止底盘的外环 PD，积分默认关闭；
- 摆角限幅和显式 `dt`。

首个版本明确不实现 Kalman、模型前馈、底盘运动 Topic、扰动观测器或自动参数辨识。
这些功能只在对应基线测试证明必要后再逐项设计和授权实现。

## 15. 系统级缺口与风险（评审结论）

以下问题来自对本方案的全局性评审，按重要性排序。共同根因是：方案把“底盘对球”
的耦合窄化成了一个标量（纵向加速度命令），而真实耦合至少有四条通道——纵向加速
度、车体俯仰姿态、前馈/扰动时间滞后差、振动与测量污染。第 11 节的最终候选结构只
覆盖了第一条。

### 15.1 缺少面向 ±1cm 指标的系统级误差预算

`+/-1 cm` 是全卷最硬的指标（第 4/5/6 项共 60 分），但方案没有把它分解到各误差源：

- 测量链：相机标定、视差/透视、振动模糊、像素分辨率；
- 摆角链：电机角到摆杆角的连杆非线性与回差、摆杆零点漂移、车体俯仰（见 15.3）；
- 控制残差：反馈带宽内压不掉的扰动。

没有该预算，第 13 节的分级门槛就没有量化判据——例如“L4 最大误差多大算纯 PID
够用”应有类似 `<= 7 mm`（给测量和机械留 `3 mm`）的数字，而不是定性描述。L5 的
“按证据加增强”路由也应由预算中哪一项超支驱动，而不是现场观感。

同一问题的另一面：球的动力学真实输入是“摆杆相对重力的角度”，而当前只观测电机
角。连杆非线性、回差、零点、车体姿态全部塌缩成一个未观测误差，只能靠相机外环补
偿，而外环带宽被相机延迟卡死（见 15.2）。第 9 节把“是否使用独立摆杆角度传感器”
列为普通待确认项，实际该决策应由误差预算推导——它是全方案少数能结构性降低误差
的选项。

### 15.2 全链路无延迟预算，前馈与扰动通道无时间对齐

闭环延迟从未量化：相机曝光 + 帧周期（30 fps 即 `33 ms`）+ 图像处理 + 传输 +
`10 ms` 控制周期 + 无刷伺服响应 + 连杆，总延迟估计 `80..120 ms`。球-杆是双积分
对象，该延迟把外环剪切频率压到约 `1 Hz` 以下；而底盘启停瞬态本身是约 `1 s` 时间
尺度的扰动，正好落在反馈带宽边缘。结论：L4 纯 PID 大概率不够、底盘加速度前馈几
乎必然要加，应提前预算而不是当成小概率增强。

前馈路径的时间对齐问题更隐蔽：

```text
扰动路径：电机命令 -> 轮胎 -> 车体真实加速度        （电机/打滑滞后）
补偿路径：a_commanded -> 伺服 -> 连杆 -> 摆角       （执行滞后）
```

两条路径滞后不相等时，前馈会在瞬态前后先制造一个反向扰动再补偿。第 5 节只要求
“及时、平滑”，缺少对齐机制（如给 `a_commanded` 增加可调纯延迟，对齐实测响应）。
混合速率执行也未定义：前馈应按 `100 Hz` 更新、反馈按相机帧更新；13.3 节“两帧之
间保持上次摆角命令”若照字面实现，会把前馈通道也降到帧率。

### 15.3 车体俯仰/横滚直接叠加进摆杆角，完全未建模

摆杆固定在车体上，车体相对重力的姿态变化 1:1 进入摆杆有效角度。来源包括加减速时
轮胎/结构压缩引起的俯仰、广告布场地褶皱和接缝、载荷分布变化。量级对比：首轮控制
命令限幅只有 `+/-2 deg`，而 `0.3..0.5 deg` 的车体俯仰并不罕见，相当于控制权限的
15..25%（换算同 `1 deg ~= 0.122 m/s^2`）。该扰动既不在 `a_commanded` 中，也不被
任何现有传感器观测（除非用车载 IMU 俯仰角补偿），最终全部落到低带宽相机外环。它
可能是 L4 阶段“弯道/接缝处莫名偏差”的第一嫌疑人，但 13.6 的证据路由表中没有对
应条目，需要补充：

- 偏差与场地固定位置（接缝、褶皱）相关：优先怀疑车体姿态耦合，评估 IMU 俯仰补偿。

### 15.4 弧长坐标全程无绝对修正，误差在曲率切换点爆发

红外弱纠偏只观测横向误差；路径导航的核心自由度是弧长坐标 `s`——曲率前馈在哪里
开始转弯完全由 `s` 决定，而 `s` 是纯里程计，从出发到 A 点检测之间没有任何绝对修
正。轮径标定 2% 误差跑到第一个弯入口（约 `3 m`）即有 `+/-6 cm` 弧长误差，等价于
在直线上提前/滞后 `6 cm` 施加 `kappa = 2` 的转弯前馈，瞬间制造约 `7 deg` 航向误
差和数厘米横向偏移。此时要靠限幅仅 `0.05..0.1 rad/s` 的弱纠偏花 `1 s` 以上收回：
前馈失配最大的位置恰好是纠偏权限最小的位置，且每圈在 4 个曲率切换点重复发生。

连锁的几何一致性问题：4.3 节的前视平滑意味着车在切换点有计划地偏离黑线，偏离量
是前视距离和速度的函数；红外阵列捕获范围只有约 `+/-4 cm`。若规划偏离与 `s` 误差
偏离之和超出捕获范围，红外会在每个弯道入口系统性丢线。当前方案缺少：

- 丢线行为定义（保持当前角速度、降速、还是停车）；
- 圈中修正 `s` 的手段（例如用陀螺仪累计转角识别弯道进出、或弯道入口线形特征）；
- “前视距离 + 预期偏离量 + s 误差”对红外捕获范围的几何核算。

这是“已知路径导航”总体方案的成立性前提，应在实物验证前先完成上述核算。

### 15.5 跨子系统时序与模式参数缺少全局定义

按键按下即开始计时，之后底盘发车、球控投入，该顺序中存在真实设计决策：第 6 项球
放在任意指定位置时，发车瞬间球控是否已收敛？“先稳球再发车”（消耗圈时，`30 s`
预算下可行）与“边发车边收敛”（起步加速与估计器暖机叠加，最坏工况）需要明确选择
和仲裁者。

各测试模式需要不同的速度规划、红外纠偏限幅和停车/过线行为，当前散落在各节的单一
数值中。需要一张“模式 × 参数”全局表和一个顶层状态机，至少包含：

```text
模式        巡航速度       红外限幅        末段行为
纯小车一圈   >=0.35 m/s    分档放大        减速停车 + 停车补偿
带球 AB     ~0.25 m/s     低速档          通过 B 后自然处理
带球一圈     ~0.25 m/s     低速档          通过 A 锁定计时，不急停
静止滚球     0             不适用          不适用
```

注意 4.5 节 `0.05..0.1 rad/s` 的限幅按带球低速设计；纯小车模式速度需 `0.35 m/s`
以上，同一限幅下轮距标定 5% 误差半圈可累计约 `9 deg` 航向误差，需按模式分档核算
收敛能力与投影不脱线约束。

另一个会直接翻车的细节：底盘 `+X`、摆杆 `+X`（指向自由端）、相机像素轴三者的对
齐关系没有定死。摆杆自由端朝车头还是车尾直接决定底盘加速度前馈的符号，必须在机
械装配约定中写明并在 L0 验证。

### 15.6 调试路线纯串行且未映射到得分项

底盘 10 步与滚球 L0..L5 是一条串行链，但两条链在 L4 之前几乎零依赖，应双线并行。
各级别应对应到得分项，以支持现场关键路径取舍：

```text
滚球 L3 通过          -> 锁定第 3 项 13 分
底盘链第 8 步通过      -> 锁定第 2 项 16 分
滚球 L4/L5 + 底盘全链 -> 第 4/5/6 项共 60 分
```

有此映射后，“时间不够时放弃 L5 只交 L4 水平”的得分损失可以预先算出。各级门槛
条件需配合 15.1 的误差预算量化后才能指挥现场取舍。

## 16. 简单起步清单（先做这些，不需要看懂第 15 节）

第 15 节是系统级风险备忘，供后期查阅，不阻塞起步。当前从最简单、不依赖任何控制
理论的步骤开始，两条线可以同时进行：

### 16.1 底盘线（对应第 8 节步骤 1..3）

1. 给左右电机各发一个固定 PWM，确认车往前走、编码器计数变大。方向反了就改接线
   或在代码里取反，并记录在案。
2. 推车走 `1 m`，读编码器计数，算出每毫米计数值。重复三次取平均。
3. 给几档固定 PWM（如 20%/40%/60%），分别记录稳定后的轮速，得到第一版
   速度—PWM 前馈表。左右轮分开记。

做完这三步就有了轮速闭环的全部标定数据，之后再看 4.2 节。

### 16.2 滚球线（对应 13.1 L0，无球、无相机、无算法）

1. 把钢球拿掉，给无刷电机发固定角度命令，用手机拍下摆杆，确认：命令正角时摆杆
   往哪边倾、回零后是否回到原位。
2. 按 13.1 的角度序列（`+/-0.5 -> +/-1 -> +/-2 deg`）跑一遍，用直尺或手机水平仪
   量实际摆杆角，记进表格。
3. 确认摆杆自由端朝车头还是车尾，写进本文件（这决定以后前馈的正负号，见 15.5）。

### 16.3 暂时不要做的事

- 不写任何 PID、Kalman、前馈代码；
- 不接相机；
- 不让底盘和滚球两个系统产生任何数据交互。

两条线各自完成上面三步后，底盘线进入第 8 节步骤 3（轮速 PI），滚球线进入 13.2
（L1 放球测试）。每一步只做一件事，做完记录数据再进下一步。
