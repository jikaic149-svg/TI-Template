# Device 参数台账

最后核对日期：2026-07-29

本文件记录工程中每个 Device 的实物型号、部署归属、连接方式、配置参数、
软件默认值和安全限制。记录时使用以下状态：

- **代码默认**：当前源码中的默认值，只说明软件行为，不代表实物已经这样配置。
- **已确认**：由实物、原理图、数据手册或用户确认的信息。
- **待确认**：当前没有可靠来源，禁止根据模块名称或常见接法猜测。

参数来源优先级为：实物丝印/原理图与 BOM、厂家数据手册、用户确认、当前源码。
同一类 Device 如果在不同产品中使用不同实物，必须分成多个“设备实例”记录。

### G3519 电机驱动 profile

电机型号和驱动芯片独立选择。模板保持一个 `Device_Motor` 公共接口，在编译期
通过 `MSPM0_MOTOR_DRIVER` 选择互斥 BSP backend，不在运行时切换。

| Profile | MSPM0G3519 资源 | 输出行为 |
|---|---|---|
| `TB6612`（默认） | PC2/TIMA0_CCP0、PC4/TIMA0_CCP1；PA24..PA27 方向 GPIO；PB21 STBY | 正反转由方向 GPIO + PWM 控制 |
| `AT8236` | PC2/CCP0、PC4/CCP1、PB20/CCP2、PA25/CCP3；TIMA0 四路同步 20 kHz PWM | 正转 `PWM/0`、反转 `0/PWM`、滑行 `0/0`、刹车 `1/1` |

AT8236 与 TB6612 的 SysConfig、BSP Motor source 和构建目录彼此隔离。没有
新增运行时状态机，也没有改变 `Device_Motor` API。
