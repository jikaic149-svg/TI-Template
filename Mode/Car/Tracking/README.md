# Tracking

循迹控制 Mode。输入只有循迹偏差、丢线/交叉口状态、基础速度和时间；输出仅是
左右轮速度意图，不读取传感器、不控制电机、不依赖 MCU。丢线时始终输出停车；
交叉口是否停车由 `stop_on_intersection` 配置。

`vision_track_mode` 是视觉循迹串级闭环：相机提供归一化横向误差和航向误差，
Mode 将两者合成为当前 yaw 偏置，再由 yaw 控制器产生差速轮速，最后由左右轮
速度控制器输出 effort。默认基础速度 400 mm/s、横向误差增益 15°、转向偏置
限幅 ±10°。丢线时立即清空两层控制器并输出零，不沿用旧视觉误差。
